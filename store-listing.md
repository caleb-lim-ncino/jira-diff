Improves readability of Jira ticket diffs.

Jira Diff Highlighter is a browser extension for Chrome, Edge, and Firefox that enhances the readability of Jira issue history diffs, including custom fields such as Acceptance Criteria and Product Copy. Review changes in Git-style line diffs or full side-by-side comparisons.

Key Features:
- Git-Style Diff View: See added and removed lines with line numbers, hunk headers, and highlights within modified lines.
- Preview Options: Choose Git-style side-by-side or unified diffs, showing changed lines or all lines. Side-by-side with only changed lines is the default. Configure zero to twenty context lines around changes.
- Raw Formatting: Preserves heading markers, asterisks, indentation and trailing spaces as plain text.
- Expand Unchanged Lines: Expand hidden sections or show all lines within an individual preview.
- Custom Fields: Automatically enhances field updates shown as old and new values in Jira history, including additions and cleared values. No field-name configuration is required.
- Highlighted Changes: Clearly see additions, deletions, and modifications with color-coded highlights.
- Configurable Large Change Handling: Choose the character limit for collapsing large insertions or deletions, keeping long Jira updates readable without cluttering the page.
- Show Full Text: Expand any collapsed large change inline when you need to inspect the full insertion or deletion.
- Toggle On/Off: Switch between enhanced and original diff views from the extension popup.
- Multi-Tab Support: Maintains consistent state across multiple Jira tabs.
- Custom Jira Domains: Atlassian-hosted Jira works automatically, and custom Jira domains can be enabled with explicit per-site access.

Perfect for:
- Developers reviewing code changes
- Project managers tracking requirement updates
- QA testers following bug report modifications
- Anyone who frequently works with Jira issue descriptions and custom fields

Jira Diff Highlighter works automatically on Atlassian-hosted Jira instances using atlassian.net subdomains. If your team uses Jira on a custom domain, you can add that domain from the extension popup and grant access only to that site.

Open Source

Jira Diff Highlighter is an open-source project. You can view the source code, contribute, or report issues on GitHub:

https://github.com/richiehowelll/jira-diff

Note: This extension enhances field diffs already displayed in Jira history. It does not alter any Jira data.
